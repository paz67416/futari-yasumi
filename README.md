# ふたりの休み合わせカレンダー（お試し版）

ふたりの勤務の形（4勤2休・3勤3休などの交替勤務、土日祝休みなど）を選ぶと、ふたりとも休みの日をカレンダーで出すページです。次にふたりとも休みの日、2日以上続けて休める日、土日ともふたりで休める週末も出ます。

- 使う：https://paz67416.github.io/futari-yasumi/
- 完全版（毎月のシフト表の入力・有給で連休をつくる日の案・3人まで・好きな月と年・その日だけの変更・印刷・画像・スマホのカレンダーへの取り込み・設定のURL保存）は note の記事で案内しています：https://note.com/chodo_lab/n/n78d5c4de8629

1枚のHTMLで動きます。入力した内容は保存も送信もしません。
